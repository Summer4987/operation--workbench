# 熊小小企微工作助手

通过企业微信官方智能机器人长连接，在 Mac mini 上运行独立服务。

支持经营日报查询、日配/成都/北京订货只读查询、粘贴聊天总结、TXT/CSV/XLSX材料分析、Excel附件生成。只在已绑定老板账号的单聊中提供业务数据，不接管微信账号，不收集未发送给机器人的聊天，不执行订货、付款、推广或发布操作。

## 配置与部署

生产代码必须由 Mac mini 从 GitHub main 拉取到独立干净副本。不要覆盖已有生产目录的本地修改。

- Node >=22，`pnpm install --frozen-lockfile --ignore-scripts`。
- 企微凭据：`~/.config/wecom-assistant/.env`，文件权限 600，键 `WECOM_BOT_ID`、`WECOM_BOT_SECRET`。
- 模型复用 `~/.xiong-agent-env` 中的 `AGENT_LLM_API_KEY`、`AGENT_LLM_BASE_URL`、`AGENT_LLM_MODEL`。
- `.env` 使用简单 `KEY=value` 格式，解析器不会执行 shell。
- 可选 `WECOM_DATA_ROOTS` 为JSON路径数组，默认只读现有 production 和 operation-workbench-clean 目录；每种日报按生成时间选择最新数据。
- 云端订货通过现有 `~/.ssh/xiong_operation_cloud_ed25519` 读取固定目录，默认 SSH `ubuntu@139.155.148.169`；SQLite使用mode=ro，不调用写接口。
- `node app.mjs --smoke` 验证企微认证、模型调用、Excel生成和临时素材上传。不要与常驻实例同时运行，避免挤掉连接。
- 只在 Mac mini 上执行 `/bin/zsh install_macmini.zsh` 安装 launchd。
- 健康检查仅监听 `http://127.0.0.1:18769/health`，无公网管理页面。

首次部署后在 Mac mini 运行 `node app.mjs --pair-code` 获取绑定口令，在企微机器人单聊发送完整口令。口令有效期24小时，仅绑定一次，绑定后其他账号和群聊不能读取业务数据。需重新生成过期口令时，在服务停机后由管理员删除未绑定的 access.json 再启动，已绑定账号不要用此法重置。

会话上下文、账号绑定、消息去重、上传文件、Excel及健康状态保存在 `~/.local/share/xiong-wecom-assistant`，不进入GitHub。上下文保留最近12条消息。`清除本次记忆`仅清除当前私聊上下文，不删除上传原件和表格。按业务需要由管理员定期清理私人文件。

模型通过既有配置的API供应商处理用户发送的内容和相关业务查询结果；不发送完整聊天库，最多向模型提供400条查询明细，Excel可保留20000行完整明细。超过范围需缩小查询。

## 验证

`node --test test.mjs test_features.mjs` 和 `python3 -m unittest discover -s . -p 'test_*.py'`。

正式交互验收：绑定后分别发送“帮助”“昨天经营概况”“今天北京门店谁未订货”“今天日配明细生成Excel”，并粘贴一段聊天要求提取待办。以真实企微回复及附件为准。

## 响应时间与余额

普通问答单次模型调用最多25秒，整个AI任务最多55秒，超时主动中止并回复重试提示。进度提示区分理解问题、读取数据、整理回答与生成文件；本机健康状态记录最近任务阶段和耗时，不记录消息正文。

老板私聊发送“模型余额”“余额”“模型额度”会直接查询DeepSeek官方余额接口，不额外调用模型。余额属于所配置API Key的账户，同一账户的其他应用也会消耗余额。充值需由用户在开放平台操作，助手不自动付款或充值。

向DeepSeek官方API发送完成业务问答所需经营和订货数据，须取得用户明确授权。当前用户已于2026-10-21在本聊天授权用于业务问答和排障；不包含客户联系方式、凭据或完整聊天库。

## 易代仓入库与常用报表

用户已确认入库沿用“易代仓预约.xlsx”。默认只读 `~/Desktop/熊小小/易代仓预约.xlsx`，可在私密.env配置 `WECOM_INBOUND_TEMPLATE` 指定另一个模板。Sheet1为预约字段，Sheet2为商品编码、品名、规格、储存方式与单位字典。原模板保留，每次新文件只包含本批入库，保留商品字典和原格式，不向库存数据库或平台提交。

示例：“明天入库：鸡胸100件，鸡腿50件，生成易代仓预约表”。支持多行、多项、明确日期、明天/后天、中文整数。缺省日期用当天，缺省仓库为成都易代仓，缺省单位用模板字典；保留用户输入单位，不进行箱/斤/公斤换算。未知或歧义商品、数量与原文不符会要求澄清，供应商字段不猜填。请将本批日期及商品数量放在同一条消息中。

品名、数量、单位明确的常见入库请求直接在本机解析并生成原模板文件，不依赖模型响应。复杂表达才进入AI工具流程。已经成功生成的附件不会因后续AI文字总结超时而丢失。

安装时由运维进程读取并验证原易代仓模板，复制数据到 `~/.local/share/xiong-wecom-assistant/templates/inbound.xlsx`；常驻服务只读私密工作目录副本，避免后台进程读取桌面文件时被系统文件访问限制阻塞。原模板不变，模板数据不进入GitHub；原模板更改后重新运行安装脚本刷新副本。

若需要补发用户明确请求但失败的入库表，运行 `node recover_inbound.mjs --send "用户请求原文"`。机器人在线时，通过仅监听127.0.0.1且要求本机私密随机令牌的运维入口，在同一常驻进程、同一连接内生成和补发，以此验收真实运行环境。该入口不接受任意收件人，只发已绑定老板；按账号、当日和请求摘要去重，收到文件发送回执后保存本机收据。未在线时保留独立恢复方式，结束后需重新启动常驻服务。缺省不带 `--send` 时只生成文件，不发送。

常驻服务在本机保存最近一条请求原文与时间供排障，不上传GitHub；运维令牌在私密目录内以600权限保存，不通过健康检查或日志输出。

经营对比使用 `compare_business`：两段等长、不重叠期间，只比较同一门店、同一平台、两期逐日完整且收入/订单均有效的记录。遗漏或重复记录的平台排除，零基数变化率留空。工具返回程序计算的差额与变化率，不由模型猜算。导出经营对比含可重算的差额/变化率公式及两期原始明细。

`query_business(export_excel=true)` 导出门店汇总、经营明细和口径。`query_orders(export_excel=true)` 导出按门店/渠道/SKU/品名/单位分组的订货汇总、完整明细和门店订货状态。不同单位不合并计数；报表保留统计期间、源数据时间及缺失提示。

`fixtures/inbound-template.xlsx` 为人工合成回归测试模板，含虚构旧预约行以验证新批次清理；不来自生产私人文件。原始测试文件由Artifact Tool生成，OOXML命名空间规范化以兼容ExcelJS读取。

### 实时销售单量

“加盟店的实时单量/订单量”读取 Mac mini 正式 `outputs/realtime_order_income/latest.json`，与采购订货接口完全分开。明确的实时请求直接查询并按平台计算，不经过模型；其他问答可以调用 `query_realtime`。回复注明采集时间，超过60分钟或跨日标记过期；每日重置和账号退出占位不作为真实零单。仅覆盖源文件里的加盟门店，不宣称主动刷新平台。可按已有门店名、美团/饿了么筛选，可导出带口径说明的经营表格。

安装器将 `WECOM_DATA_ROOTS` 设为 Mac mini 的正式生产产物目录，避免后台进程读取旧 Documents 副本。仅本机令牌可调用 `POST /operator/realtime`（`{ "text": "加盟店实时单量" }`），调用常驻 Assistant 并返回只读结果，不向企微补发消息。

### 私人长期记忆和公开搜索

长期记忆保存于 Mac mini 私有运行目录的 `memory/facts.json`（600），不入 GitHub；只接受绑定账号的显式命令，不从模型或网页自动写记忆。支持“记住：内容”“查看记忆”“搜索记忆 关键词”“修改记忆 ID 新内容”“删除记忆 ID”“清空长期记忆”（需二次明确确认）。每条上限1000字、最多500条。修改、删除会同时清除近期对话上下文，防止旧内容继续被引用；原上传文件、已生成表格不随之删除。密码、密钥、证件和银行卡信息不写入记忆。不要把这里当密码管理器。

`WECOM_MEMORY_ENABLED=1` 默认开启本地管理；`WECOM_MEMORY_MODEL_CONSENT=0` 默认关闭外部模型使用记忆。用户允许后才设置为1。按关键词与中文二元词检索至多6条相关记忆，不宣称永久记住所有聊天，也不自动读取其他微信聊天。

`WECOM_SEARCH_ENABLED=0` 默认关闭，收到用户授权再设置为1。用户明确发送“联网搜索：公开关键词”时，只有该搜索词发送给 Bing 公开RSS搜索；不附加本地记忆、历史聊天或业务工具数据。明显涉及私人或内部信息的查询拦截并请用户改写为公开关键词，不做静默发送。搜索结果视作不可信资料，不能写长期记忆或执行工具；回答附真实标题和链接，并说明仅见搜索摘要、未读取全文。搜索入口无额外密钥，结果受入口可用性和相关性限制；失败时明确告知，不能假装联网。摘要整理仍使用当前DeepSeek调用额度，失败时保留来源列表。

三项开关可放在 Mac mini 私有 `.config/wecom-assistant/.env`，授权记录及密钥不提交 GitHub。变更后重启正式服务。`/health` 返回实际开关。受本机令牌保护的 `POST /operator/ask` 在同一常驻Assistant内验收，不主动向企微发消息；可执行助手已有的本地记忆管理指令，令牌须保密。验收请求带 `verification:true` 时只使用独立的私有 `verification/personal` 目录，不改动用户的真实记忆和对话上下文。
